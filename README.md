# BookNest API

A Library Management REST API built using:

- Node.js
- Express.js
- TypeScript
- PostgreSQL
- node-postgres (pg)

## Features

- Book Management
- Author Management
- Member Management
- Book Borrowing
- Book Returns
- Borrowing History

## Database

PostgreSQL with manually written SQL queries.

No ORM is used.

## Installation

npm install

## Development

npm run dev
